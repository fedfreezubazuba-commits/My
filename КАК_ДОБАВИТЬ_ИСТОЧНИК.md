# Как добавить источник

Большинство сайтов добавляются **без программирования** — через мастер «Найти данные → Сайт»
(таблица на странице, цена на странице) или «Файл» (xlsx/csv/pdf по ссылке, папка «Входящие»).
Этот документ — для случаев, когда мастер не справился и нужен свой адаптер. Его пишет Claude Code
по пакету «Отправить Claude».

## 0. Может, хватит профиля сайта?

Если страница обычная, но цена лежит хитро (как у METRO: цена за кг — в состоянии страницы
`window.__NUXT__`), проще добавить **профиль сайта** — модуль в `hub/sources/sites/`:

```python
DOMAINS = ["example-shop.ru"]
NAME = "EXAMPLE"
FIELDS = {"price": ("цена", "руб./шт")}


def extract(text, doc=None):
    from .. import _web as W
    doc = doc if doc is not None else W.parse_html(text)
    return {"price": W.anchor_number(doc, "Цена:")}
```

Мастер «Сайт» сам применит профиль к ссылкам этого домена (см. `sites/metro.py` и тест
`tests/test_web.py::test_metro_wizard_and_fetch`). Таблицы на страницах и «плитки» обычно
распознаются без профиля (`_tables.py`).

## 1. Сохраните образец

Положите ответ источника в `samples/<источник>/` (HTML-страницу, JSON, файл). Без образца адаптер
не проверить: из облака многие сайты недоступны. Личные данные и куки из образца уберите.

## 2. Напишите адаптер

Файл `hub/sources/<имя>.py`. Регистрация автоматическая — достаточно класса-наследника `Source`
с заполненным `kind`.

```python
"""Пример: курс с условного сайта example.ru (одно число на странице)."""
import datetime as dt

from ..core import periods as P
from ..core.errors import StructureError
from .base import FetchResult, Obs, SeriesInfo, Source


class ExampleRate(Source):
    kind = "example_rate"            # короткое имя, хранится в jobs.yaml — потом не менять
    title = "Курс с example.ru"      # так источник называется в интерфейсе
    snapshot = True                  # True — история строится из ежедневных снимков

    def fetch(self, params, ctx) -> FetchResult:
        html = self.download(params["url"], ctx)          # ваш способ получить данные
        value = P.parse_number(self.find_value(html))     # «1 979,50 ₽» → 1979.5
        if value is None:
            raise StructureError("На странице не найдено число курса")   # → «Нужна правка»
        today = ctx.now.date()
        key = "rate"                                      # стабильная идентичность ряда — не менять!
        return FetchResult(
            series=[SeriesInfo(key=key, name="Курс EXR", unit="руб.", periodicity="snapshot",
                               code="EXAMPLE_rate", url=params["url"], date_rule="дата снимка")],
            obs=[Obs(key=key, period_end=today, period_label=today.isoformat(), value=value)],
            raw=html.encode("utf-8"), raw_ext="html", url=params["url"])

    def check_updated(self, params, ctx):
        return None      # дешёвой проверки нет — runner загрузит по расписанию
```

Правила:

- `SeriesInfo.key` — стабильная идентичность ряда внутри показателя. От неё зависит код ряда, а код
  — это имя столбца в моделях пользователя. **Не меняйте key у существующих рядов.**
- `SeriesInfo.code` — предлагаемый код (латиница, цифры, `_`, до 40 символов). Хранилище присвоит его
  один раз; при совпадении добавит суффикс.
- `period_end` — конец отчётного периода (`hub/core/periods.py`: `month_end`, `quarter_end`,
  `end_of_period`); для снимков — дата наблюдения. Подпись — `periods.label(...)`.
- Ошибки — с категорией: `StructureError` (изменилась страница), `LoginRequired` (нужен вход),
  `HubError(errors.BOT, …)` (капча). Сетевые ошибки и 503/429 классифицируются сами.
- Сайт со входом: используйте `ctx.browser` (встроенный браузер с постоянным профилем). Паролей не
  храните и не вводите — входит пользователь сам.
- Вежливость: один хост — строго последовательно (это делает runner), без лишних запросов.
- Если источник сам сообщает, когда выйдут следующие данные, заполните `FetchResult.next_release`
  («2026-11-20» или «2026-11-20T19:00») и `release_note` (как источник описывает сроки). Хаб проверит
  показатель в этот момент. Берите срок из того, что уже скачано, — отдельный запрос ради него не нужен.

## 3. Тест на образце

`tests/test_<имя>.py`:

```python
from pathlib import Path

from hub.sources import Context, get

SAMPLE = Path(__file__).resolve().parents[1] / "samples" / "example" / "page.html"


def test_example_rate(monkeypatch):
    src = get("example_rate")
    monkeypatch.setattr(type(src), "download", lambda self, url, ctx: SAMPLE.read_text("utf-8"))
    res = src.fetch({"url": "https://example.ru/rate"}, Context())
    assert res.series[0].code == "EXAMPLE_rate"
    assert res.obs[0].value == 1979.5
```

Запуск: `python -m pytest -q tests/test_<имя>.py`.

## 4. Как пользователь добавит показатель

Если у источника нет своей вкладки, показатель можно добавить в `config/jobs.yaml` рабочей папки
(или через мастер «Сайт», если адаптер — профиль сайта):

```yaml
- id: example-rate
  name: Курс EXR
  source: example_rate
  params: {url: "https://example.ru/rate"}
  schedule: daily
  enabled: true
  checks: {max_jump_pct: 50}
```

Проверка без записи: `python -m hub check example-rate`.
