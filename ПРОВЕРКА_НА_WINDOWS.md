# Проверка на Windows

То, что нельзя проверить в облаке (там нет Windows, Excel и доступа к российским сайтам).
Пройдите по списку один раз после установки. Если пункт не получился — нажмите в хабе
«Отправить Claude» (или скопируйте текст ошибки) и вставьте в новую сессию Claude Code.

## 1. Установка

- [ ] `Установка.bat` запускается, русские буквы в окне читаются (не «кракозябры»).
- [ ] Если Python не установлен — открывается страница загрузки с понятной подсказкой.
- [ ] После установки открылось окно «Хаб данных» и мастер первого запуска.
- [ ] На рабочем столе появился ярлык «Хаб данных», он открывает программу без чёрного окна.
- [ ] Повторный запуск `Установка.bat` ничего не ломает.

## 2. Живые загрузки

- [ ] «Найти данные» → «Банк России»: каталог загрузился, дерево открывается.
- [ ] Выберите «Ставки по вкладам…» (категория 18, показатель 37), отметьте один срок → «＋ В обновления»
      → «Добавить». Результат: «Получено: … последнее значение … на ДД.ММ.ГГГГ».
- [ ] **Сверьте дату**: значение за январь должно стоять на дате **31.01**, а не 01.02.
      Если для какого-то показателя ЦБ дата сдвинута неправильно — напишите, какой показатель.
- [ ] «Найти данные» → «ЕМИСС»: каталог загрузился (первый раз до минуты).
- [ ] Выберите любой месячный показатель, отметьте один регион → «＋ В обновления». Результат
      без ошибки; месячные значения стоят на последних числах месяцев.
- [ ] Если ЕМИСС ответил «ограничивает частоту» — это нормально, хаб повторит позже сам.
- [ ] Общий поиск сверху «Найти данные» находит показатели ЦБ и ЕМИСС (после того как каталоги
      один раз загрузились).
- [ ] По желанию: в командной строке в папке проекта выполните
      `.venv\Scripts\python -m hub samples` — сохранятся живые ответы ЦБ и ЕМИСС в `samples\live\`.
      Пришлите эту папку (или закоммитьте) — по ней Claude дополнит тесты.

## 2а. Сайты и файлы

- [ ] `Установка.bat` поставил встроенный браузер (строка «[4/5]» без сообщения «не установился»).
- [ ] «Сайт» → ссылка на лосось в METRO
      (`https://online.metro-cc.ru/products/losos-murmanskij-6-7kg-inarctica`) → «Найти данные на странице».
      Показаны цена за штуку, за кг и наличие. Если сайт не пустил (защита) — хаб сам открыл страницу
      встроенным браузером; если и так не вышло — нажмите «Войти на сайт…», выберите магазин, закройте окно,
      повторите.
- [ ] Цены совпадают с тем, что видно на сайте **для вашего магазина**. Если нет — напишите, какие числа
      на сайте и какие показал хаб.
- [ ] «Сайт» → `https://www.metaltorg.ru/` → вкладка «Таблицы»: есть «Цветные металлы», «Биржевые цены на
      сталь», «Драгоценные металлы». Добавьте «Цветные металлы» → «Получено: 6 рядов…».
- [ ] Закрытые разделы Металл Торг: «Войти на сайт…» → войдите своим логином → закройте окно → «Найти
      данные на странице» на закрытой странице показывает таблицы.
- [ ] «Сайт» → `https://fearnpulse.com/fearnleys-weekly-report`: страница строится скриптом, хаб читает её
      встроенным браузером (в сообщении «прочитана встроенным браузером»). Есть таблицы «Dirty (Spot WS…)»,
      «Capesize…», «1 Year T/C…». Дата отчёта — дата из «Week NN - …».
- [ ] «Настройки» → «Добавить примеры…» → через минуту на «Обзоре» нет красных статусов (или понятно, почему).
- [ ] «Выбрать на странице…» открывает окно, при наведении элементы подсвечиваются, щелчок по числу
      возвращает значение в хаб.
- [ ] «Файл»: ссылка на любой xlsx/csv/pdf с таблицей открывается, превью видно.
- [ ] «Файл» → «Выбрать файл и положить во „Входящие“» → «＋ В обновления»; положите в ту же папку
      новую выгрузку → «Обновить сейчас» → новые даты появились, файл переехал в «обработано».
- [ ] В фоне (автообновление, окно хаба закрыто) показатели METRO и Fearnleys тоже обновляются.

## 2б. После версии 0.3

- [ ] «Модели» → «Проверить связь с Excel»: окно с журналом, в нём хотя бы один способ «таблица создана».
      Текст уже в буфере обмена — пришлите его Claude, даже если подключение модели работает.
- [ ] Подключите копию модели ещё раз. Ожидаемо одно из двух: «подключена» или «почти подключена»
      (тогда выполните 2 действия из сообщения). Модель открывается, лист «Хаб» с данными.
- [ ] ЕМИСС: добавьте тот самый большой показатель (цены с 2016/2017 года) со всеми годами. Внизу окна
      видно «загружаю частями: 2016–2019…», загрузка заканчивается успешно (может занять минуты).
- [ ] «Банк России»: годы выбираются списком с галками, как в ЕМИСС; «Последние 5» работает.
- [ ] «Открыть в Excel» у показателя ЕМИСС: на листе «Длинная» регион, вид продукции и т.п. — отдельные
      столбцы, единицы — в столбце «Единицы» (без «^»).
- [ ] Fearnleys: «Выбрать на странице…» → щелчок по всему блоку ставок → хаб предлагает таблицу
      (каждая строка — ряд) → «Добавить» → пробная загрузка проходит.

## 2в. Выжимка для модели (версия 0.4)

- [ ] Подключённая модель: в нижнем списке «Модели» выделите строку «Весь показатель: …» (если она есть
      после прежних проверок) → «Изменить выборку» → отметьте один товар, один регион, «месячная»,
      период «с 2022» → «Сохранить». В списке — «Выборка: …» и только подходящие ряды.
- [ ] В модели «Данные → Обновить всё»: в таблице «Хаб» только эти столбцы и даты с 2022 года;
      в «Хаб_Ряды» у каждого ряда отдельные поля «Показатель», «Разрез 1…».
- [ ] Добавьте большой показатель с галкой модели в диалоге «＋ В обновления»: после загрузки хаб
      не отдаёт его в модель целиком, а предлагает «Выбрать данные для модели».

## 2г. Расписание и график выхода (версия 0.5)

- [ ] После обновления программы откройте её один раз: задача в «Планировщике заданий Windows» сама
      сменилась на запуск каждые 15 минут (свойства задачи → «Триггеры»).
- [ ] «Мои показатели» → «Изменить» у любого показателя → «По дням недели», отметьте сегодняшний день,
      время через 20–30 минут → «Сохранить». Не открывая хаб, дождитесь этого времени: в течение 15 минут
      показатель обновился («Последняя попытка» в списке).
- [ ] «График выхода…» → вставьте кусок календаря публикаций с сайта Росстата или ЦБ → внизу окна видно
      «Нашёл дат: …» с правильными датами. Если какие-то даты не нашлись — пришлите Claude этот текст.
- [ ] ЕМИСС: после загрузки показателя откройте «История». Если там есть строка «Источник о сроках: …» —
      сверьте её с сайтом. Если строки нет, а на странице показателя на fedstat.ru срок указан — выполните
      `.venv\Scripts\python -m hub samples` и пришлите Claude файл `samples\live\fedstat_indicator_*.html`
      (так Claude увидит, как ЕМИСС на самом деле пишет срок, и научит хаб его читать).

## 3. Планировщик (автообновление)

- [ ] На «Обзоре» включите «Автообновление». В «Планировщике заданий Windows» появилась задача
      «Хаб данных — обновление» (каждые 15 минут и при входе в систему).
- [ ] Через час (или: Планировщик → задача → «Выполнить») на «Обзоре» обновилась строка
      «Последнее обновление: …», чёрное окно не появлялось.
- [ ] Выключите автообновление — задача исчезла из планировщика.

## 4. Подключение модели

- [ ] Сделайте копию любой своей модели и подключите её: «Модели» → «＋ Подключить модель».
- [ ] Если модель открыта — хаб просит её закрыть и ничего не меняет.
- [ ] После подключения: в `C:\MarketData\backups\модели` есть копия; в модели появился лист «Хаб»
      с таблицами `Хаб` и `Хаб_Ряды`; остальные листы не изменились.
- [ ] «Данные → Запросы и подключения»: есть запросы `Хаб_Посылка`, `Хаб`, `Хаб_Ряды`.
- [ ] Excel не задаёт вопросов про «уровни конфиденциальности» при обновлении.
- [ ] Если подключение через Excel не сработало — появился файл «<модель> — подключение.xlsx»
      и инструкция «… — как подключить вручную.txt». Проверьте, что по инструкции получается.

## 5. Обновление в Excel

- [ ] «Модели» → «＋ Данные для модели» → показатель ЦБ → отметьте значения и период → «Добавить в модель».
- [ ] В модели «Данные → Обновить всё»: в таблице `Хаб` появился столбец с кодом ряда, даты по
      возрастанию, числа — числами (не текстом), даты — датами.
- [ ] Добавьте в подписку второй ряд → «Обновить всё»: новый столбец появился **справа**, старый
      остался на месте, формулы на него не сломались.
- [ ] Закройте и откройте модель — данные обновляются при открытии.
- [ ] Модель открывается на другом компьютере без хаба (данные на месте, просто без обновления).

## 6. Формула

- [ ] «Мои показатели» → «Формула» → «Копировать» → вставьте в ячейку модели рядом с датой
      конца месяца — формула считает значение.
- [ ] Переключатель «Excel на английском» даёт формулу с `XLOOKUP` и запятыми.

## 7. Уведомление и отчёт

- [ ] После обновления с новыми данными появляется всплывающее уведомление Windows
      «Новые данные в моделях…». В настройках его можно выключить.
- [ ] `Обновить сейчас.bat` обновляет всё и открывает отчёт в браузере; на вкладке «Отчёты» он тоже есть.

## 7а. Мелочи этапа 2

- [ ] «Мои показатели» → «Открыть в Excel» открывает файл с листами «Данные», «Последние», «Длинная», «Паспорт».
- [ ] «Настройки» → «Также сохранять файл по каждому показателю» → после обновления в
      `C:\MarketData\Выгрузки\Показатели` появились файлы.
- [ ] «Удалить» показатель → он в «Корзине…», «Восстановить» возвращает его с данными.
- [ ] «Отправить Claude» (на «Обзоре» у ошибки или в «Ещё ▾») — текст в буфере обмена, в нём нет паролей и куки.

## 8. Ошибки и восстановление

- [ ] Откройте файл `C:\MarketData\Для моделей\<модель>.csv` в Excel и нажмите «Обновить всё сейчас»
      в хабе: обновление не падает, в отчёте сказано, что файл занят; после закрытия файла и
      следующего обновления данные записываются.
- [ ] Отключите интернет и нажмите «Обновить всё сейчас»: статусы «Сбой, повторю позже», после
      включения интернета — снова «Обновлено»/«Без изменений».
