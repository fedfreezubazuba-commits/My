# Проверка на Windows

То, что нельзя проверить в облаке (там нет Windows, Excel и доступа к российским сайтам).
Пройдите по списку один раз после установки. Если пункт не получился — нажмите в хабе
«Отправить Claude» (или скопируйте текст ошибки) и вставьте в новую сессию Claude Code.

## 1. Установка

- [ ] `Установка.bat` запускается, русские буквы в окне читаются (не «кракозябры»).
- [ ] Если Python не установлен — открывается страница загрузки с понятной подсказкой.
- [ ] После установки открылось окно «Хаб данных» и мастер первого запуска.
- [ ] На рабочем столе появился ярлык «Хаб данных», он открывает программу без чёрного окна.
- [ ] Повторный запуск `Установка.bat` ничего не ломает.

## 2. Живые загрузки

- [ ] «Найти данные» → «Банк России»: каталог загрузился, дерево открывается.
- [ ] Выберите «Ставки по вкладам…» (категория 18, показатель 37), отметьте один срок → «＋ В обновления»
      → «Добавить». Результат: «Получено: … последнее значение … на ДД.ММ.ГГГГ».
- [ ] **Сверьте дату**: значение за январь должно стоять на дате **31.01**, а не 01.02.
      Если для какого-то показателя ЦБ дата сдвинута неправильно — напишите, какой показатель.
- [ ] «Найти данные» → «ЕМИСС»: каталог загрузился (первый раз до минуты).
- [ ] Выберите любой месячный показатель, отметьте один регион → «＋ В обновления». Результат
      без ошибки; месячные значения стоят на последних числах месяцев.
- [ ] Если ЕМИСС ответил «ограничивает частоту» — это нормально, хаб повторит позже сам.
- [ ] Общий поиск сверху «Найти данные» находит показатели ЦБ и ЕМИСС (после того как каталоги
      один раз загрузились).
- [ ] По желанию: в командной строке в папке проекта выполните
      `.venv\Scripts\python -m hub samples` — сохранятся живые ответы ЦБ и ЕМИСС в `samples\live\`.
      Пришлите эту папку (или закоммитьте) — по ней Claude дополнит тесты.

## 3. Планировщик (автообновление)

- [ ] На «Обзоре» включите «Автообновление». В «Планировщике заданий Windows» появилась задача
      «Хаб данных — обновление» (каждый час и при входе в систему).
- [ ] Через час (или: Планировщик → задача → «Выполнить») на «Обзоре» обновилась строка
      «Последнее обновление: …», чёрное окно не появлялось.
- [ ] Выключите автообновление — задача исчезла из планировщика.

## 4. Подключение модели

- [ ] Сделайте копию любой своей модели и подключите её: «Модели» → «＋ Подключить модель».
- [ ] Если модель открыта — хаб просит её закрыть и ничего не меняет.
- [ ] После подключения: в `C:\MarketData\backups\модели` есть копия; в модели появился лист «Хаб»
      с таблицами `Хаб` и `Хаб_Ряды`; остальные листы не изменились.
- [ ] «Данные → Запросы и подключения»: есть запросы `Хаб_Посылка`, `Хаб`, `Хаб_Ряды`.
- [ ] Excel не задаёт вопросов про «уровни конфиденциальности» при обновлении.
- [ ] Если подключение через Excel не сработало — появился файл «<модель> — подключение.xlsx»
      и инструкция «… — как подключить вручную.txt». Проверьте, что по инструкции получается.

## 5. Обновление в Excel

- [ ] «Модели» → «Добавить ряды» → отметьте ряд ЦБ → «Сохранить».
- [ ] В модели «Данные → Обновить всё»: в таблице `Хаб` появился столбец с кодом ряда, даты по
      возрастанию, числа — числами (не текстом), даты — датами.
- [ ] Добавьте в подписку второй ряд → «Обновить всё»: новый столбец появился **справа**, старый
      остался на месте, формулы на него не сломались.
- [ ] Закройте и откройте модель — данные обновляются при открытии.
- [ ] Модель открывается на другом компьютере без хаба (данные на месте, просто без обновления).

## 6. Формула

- [ ] «Мои показатели» → «Формула» → «Копировать» → вставьте в ячейку модели рядом с датой
      конца месяца — формула считает значение.
- [ ] Переключатель «Excel на английском» даёт формулу с `XLOOKUP` и запятыми.

## 7. Уведомление и отчёт

- [ ] После обновления с новыми данными появляется всплывающее уведомление Windows
      «Новые данные в моделях…». В настройках его можно выключить.
- [ ] `Обновить сейчас.bat` обновляет всё и открывает отчёт в браузере; на вкладке «Отчёты» он тоже есть.

## 8. Ошибки и восстановление

- [ ] Откройте файл `C:\MarketData\Для моделей\<модель>.csv` в Excel и нажмите «Обновить всё сейчас»
      в хабе: обновление не падает, в отчёте сказано, что файл занят; после закрытия файла и
      следующего обновления данные записываются.
- [ ] Отключите интернет и нажмите «Обновить всё сейчас»: статусы «Сбой, повторю позже», после
      включения интернета — снова «Обновлено»/«Без изменений».
