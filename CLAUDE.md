# CLAUDE.md — для будущих сессий Claude Code

Постоянное ТЗ — `SPEC.md` (прочитай целиком). Пользователь — финансовый аналитик, **не программист**:
всё, что он видит (интерфейс, сообщения, README, отчёты), — по-русски и без жаргона.

## Выкат обновлений

Пользователь скачивает программу архивом. **В каждом сообщении о выкате обновления повторяй ссылку для
скачивания** (ветка — та, в которую ты пушишь):
`https://github.com/fedfreezubazuba-commits/My/archive/refs/heads/<ветка>.zip`
и напоминай: распаковать поверх старой папки с заменой файлов (данные в `C:\MarketData` не пострадают);
`Установка.bat` — только если менялся `requirements.txt`.

## Архитектура

```

  runner.py        фоновое обновление: блокировка, сроки, очередь по хостам, тайм-ауты, проверки, карантин, посылки, отчёт
  core/
    paths.py       рабочая папка (C:\MarketData) и её подпапки; config/workdir.txt — где она
    config.py      jobs.yaml / models.yaml / settings.yaml / trash.yaml в рабочей папке
    store.py       SQLite: series, observations (state current|old|quarantine|rejected), runs, job_state,
                   subscriptions (постоянный порядок столбцов), model_state, quarantine, meta
    schedule.py    auto | daily | weekly:Wed | monthly:15 | every:6h; ожидаемая дата и «Задерживается»
    checks.py      проверки перед записью (раздел 12 ТЗ)
    errors.py      категории ошибок + человеческие тексты и действия
    periods.py     даты/периоды/подписи (2025-01, 2025-Q1…), разбор чисел и дат с сайтов
    status.py      статусы-светофор
    report.py      HTML-отчёт запуска
    overview.py    данные для «Обзора»
    notify.py      уведомления Windows (PowerShell), на Linux — только журнал
    claude_pack.py «Отправить Claude» (с вычисткой секретов)
    winsched.py    задача планировщика Windows (XML через schtasks)
    setup.py, samples.py
  sources/         адаптеры источников; регистрация автоматическая (класс-наследник Source с kind)
    base.py        Source, SeriesInfo, Obs, FetchResult, Context
    cbr_api.py     ← legacy/cbr_client.py БЕЗ изменений логики (проверено вживую)
    fedstat_api.py ← legacy/fedstat_client.py БЕЗ изменений логики
    cbr.py, fedstat.py
    web_value.py   цена/число на странице (снимки → история); стратегии: profile, jsonld, meta, script,

    web_table.py   таблица на странице (html или «плитки»), режимы snapshot/history; ищется по подписи

    _files.py      чтение таблиц из файлов; _analyze.py — что показать в мастере «Сайт»
    browser.py     Playwright (необязателен): get_html, login (входит пользователь), pick (выбор элемента)
    sites/         профили сайтов (metro.py: цена за шт., за кг, наличие)
  excel/
    packet.py      «посылки» Для моделей/<модель>.csv и «<модель> — ряды.csv»
    templates/*.m  шаблоны Power Query (M): Хаб_Посылка (параметр), Хаб, Хаб_Ряды
    mcode.py       подстановка пути и простая синтаксическая проверка M
    com_connect.py COM-подключение модели (pywin32), файл-подключение, ночное обновление
```

Данные пользователя — в рабочей папке (вне репозитория), не в `config/` репозитория. Это осознанное
отступление от схемы в SPEC (там `config/` в проекте): так обновление кода не трогает данные и они не
попадают в git.

## Соглашения — НЕЛЬЗЯ менять

- **Коды рядов**: латиница/цифры/`_`, ≤ 40 символов, начинаются с буквы. Присваиваются один раз
  (`store.assign_code` по паре «показатель + SeriesInfo.key») и больше не меняются. Если меняешь
  адаптер — `SeriesInfo.key` существующих рядов должен остаться прежним, иначе появятся новые коды
  и у моделей пропадут столбцы. Шаблоны: `CBR_<кат>_<пок>[_m1_<id>][_m2_<id>]`,
  `FEDSTAT_<id>_<коды измерений>_<вид периода>`, `METRO_<товар>_<поле>`, `WEB_…`.
- **Порядок столбцов подписки** — таблица `subscriptions.position`, присваивается один раз; новые справа.
- **Посылка**: `Для моделей/<модель>.csv`, колонки `Дата;Период;Код;Название;Единицы;Значение`,
  UTF-8 с BOM, `;`, точка как десятичный разделитель, даты ISO, строки в порядке подписки, затем по дате.
  Справочник — `<модель> — ряды.csv` (путь M-шаблон вычисляет из параметра). Запись только при
  изменении, атомарно; занятый файл → `FileBusy`, повтор в следующем проходе.
- **M-шаблоны** не перечисляют столбцы (pivot по `List.Distinct` кодов), типы — с культурой `en-US`,
  путь — в одном параметре `Хаб_Посылка`, нет файла → понятная ошибка. Проверка: `mcode.check_syntax`.
- **Дата** = конец отчётного периода (`periods.py`). ЦБ: дата «1-е число следующего периода» → минус
  день; исходная — в `source_date`.
- **Логика запросов `cbr_api.py` / `fedstat_api.py`** (параметры, CSRF-токен, паузы, повторы при 503) —
  не менять без необходимости. ЕМИСС: запросы строго последовательно (очередь по хостам в runner).
- Модель пользователя меняем только «Подключить модель» (и опциональное ночное обновление), только с
  резервной копией, без макросов. Паролей не храним и не вводим.

## Важные механизмы (версия 0.3)

- **Разрезы отдельными полями**: `SeriesInfo.dims = [("Показатель", …), ("Регион", …)]` → `series.dims`
  (JSON). Справочник «— ряды.csv» получает в конце столбцы «Показатель», «Разрез 1…4»
  (`packet.cut_values`); «Открыть в Excel» — столбцы с настоящими названиями (`exports.dims_table`).
  Название ряда (`name`) по-прежнему склейка — для подписи. ЕМИСС: измерение «Единица измерения»
  уходит в единицы, «^» вычищается (`fedstat.clean`).
- **ЕМИСС частями**: `FedstatSource._download_in_parts` — части по годам, размер от оценки
  «значений на год» (`CHUNK_CELLS`), при сбое части — пополам до 1 года, после удачи — вдвое больше.
  Дозагрузка: runner передаёт `ctx.last_period` и `ctx.full_reload` (полная раз в 30 дней, отметка
  `meta full:<id>`); при дозагрузке `FetchResult.partial = True` — проверки «исчезли ряды» и «резко
  меньше строк» не применяются. `Source.timeout()` — свой тайм-аут источника.
- **Подключение модели (COM)**: у пользователя (Excel 16, сборка 19127, pywin32, Python 3.13) все три
  первых способа `ListObjects.Add` дали E_INVALIDARG (-2147024809), а `Queries.Add` работает. Поэтому
  `_load_tables` перебирает окружения `VARIANTS` (Excel в фоне / видимый свёрнутый × русские / латинские
  имена запросов `mcode.ASCII_NAMES`) и способы `TABLE_WAYS`; сработавшее запоминается в
  `settings.excel_way`. Таблицы на листе всегда называются Хаб и Хаб_Ряды.
  `com_connect.TABLE_WAYS` — несколько способов `ListObjects.Add`;
  ошибка называет шаг (`StepError`); если запросы добавились, а таблицы нет — модель сохраняется
  «почти подключённой» (`partial`). `com_connect.diagnose` — кнопка «Проверить связь с Excel».
  Тесты на поддельном Excel — `tests/test_com.py`.
- **«Выбрать на странице»**: щелчок по блоку с >3 числами = выбор таблицы (`_analyze.picked_table`,
  сопоставление по строкам или по тексту блока). Если нужное не нашлось, страница прикладывается
  к ошибке (`exc.raw_text` → raw) и попадает в «Отправить Claude».
- Навигаторы ЕМИСС и ЦБ используют один виджет выбора значений `gui/dimlist.py`.

## Категории ошибок

`errors.py`: network, rate_limit, structure, login, bot, file_busy, check_failed, no_new_data, internal.
Адаптер поднимает `StructureError` при непонятном ответе, `LoginRequired` — когда нужен вход.
Остальное классифицирует `errors.classify`. Временные (network, rate_limit, file_busy) повторяются с
паузой 15 мин → 30 → … → 6 ч; после `fail_threshold` (3) сбоев подряд статус красный.

## Как запускать тесты

```
pip install -r requirements-dev.txt
python -m pytest -q                       # ядро, источники, посылки, M-шаблоны
xvfb-run -a python -m pytest -q           # плюс проверка окна (в Linux без дисплея)
HUB_CHROMIUM=/opt/pw-browsers/chromium-1194/chrome-linux/chrome xvfb-run -a python -m pytest -q
                                          # плюс «Выбрать на странице» в настоящем Chromium
```

Веб-источники тестируются на сохранённых страницах `samples/web/` (Metro, Металл Торг, Fearnleys):
`tests/test_web.py` подменяет `_web.http_get`. Показатели-образцы — `hub/core/examples.py`.

В облаке Python 3.13 системы может быть без tkinter — используй `python3.12 -m venv`.
Сайты ЦБ/ЕМИСС из облака недоступны: тестируй только на `samples/` (см. `tests/fakes.py`).
Живые ответы пользователь может сохранить командой `python -m hub samples` (→ `samples/live/`).

## Как добавить источник

См. `КАК_ДОБАВИТЬ_ИСТОЧНИК.md`. Коротко: модуль в `hub/sources/` с классом-наследником `Source`
(`kind`, `title`, `fetch`, при возможности `check_updated`), тест на образце в `samples/`.

## Что проверить у пользователя

Всё, что требует Windows, Excel или живых сайтов, — в `ПРОВЕРКА_НА_WINDOWS.md`. Дополняй его, если
добавляешь такое.
