# CLAUDE.md — для будущих сессий Claude Code

Постоянное ТЗ — `SPEC.md` (прочитай целиком). Пользователь — финансовый аналитик, **не программист**:
всё, что он видит (интерфейс, сообщения, README, отчёты), — по-русски и без жаргона.

## Выкат обновлений

Пользователь скачивает программу архивом. **В каждом сообщении о выкате обновления повторяй ссылку для
скачивания** (ветка — та, в которую ты пушишь):
`https://github.com/fedfreezubazuba-commits/My/archive/refs/heads/<ветка>.zip`
и напоминай: распаковать поверх старой папки с заменой файлов (данные в `C:\MarketData` не пострадают);
`Установка.bat` — только если менялся `requirements.txt`.

Данные пользователя — в рабочей папке (вне репозитория), не в `config/` репозитория. Это осознанное
отступление от схемы в SPEC (там `config/` в проекте): так обновление кода не трогает данные и они не
попадают в git.

## Соглашения — НЕЛЬЗЯ менять

- **Коды рядов**: латиница/цифры/`_`, ≤ 40 символов, начинаются с буквы. Присваиваются один раз
  (`store.assign_code` по паре «показатель + SeriesInfo.key») и больше не меняются. Если меняешь
  адаптер — `SeriesInfo.key` существующих рядов должен остаться прежним, иначе появятся новые коды
  и у моделей пропадут столбцы. Шаблоны: `CBR_<кат>_<пок>[_m1_<id>][_m2_<id>]`,
  `FEDSTAT_<id>_<коды измерений>_<вид периода>`, `METRO_<товар>_<поле>`, `WEB_…`.
- **Порядок столбцов подписки** — таблица `subscriptions.position`, присваивается один раз; новые справа.
- **Посылка**: `Для моделей/<модель>.csv`, колонки `Дата;Период;Код;Название;Единицы;Значение`,
  UTF-8 с BOM, `;`, точка как десятичный разделитель, даты ISO, строки в порядке подписки, затем по дате.
  Справочник — `<модель> — ряды.csv` (путь M-шаблон вычисляет из параметра). Запись только при
  изменении, атомарно; занятый файл → `FileBusy`, повтор в следующем проходе.
- **M-шаблоны** не перечисляют столбцы, типы — с культурой `en-US`, путь — в одном параметре
  `Хаб_Посылка`, нет файла → понятная ошибка. Проверка: `mcode.check_syntax`. Вид таблицы «Хаб»
  (`model.layout`, `packet.layout`): `long` (по умолчанию с 0.5.4, шаблон `Хаб_строки.m`, файл
  «<модель> — таблица.csv»: Дата;Период;Показатель;<поля>;Периодичность;Единицы;Источник;Код;Обновлено;Значение)
  или `wide` (`Хаб.m`, pivot по `List.Distinct` кодов). Модели, подключённые до 0.5.4 без `layout`, — `wide`.
- **Дата** = конец отчётного периода (`periods.py`). ЦБ: дата «1-е число следующего периода» → минус
  день; исходная — в `source_date`.
- **Логика запросов `cbr_api.py` / `fedstat_api.py`** (параметры, CSRF-токен, паузы, повторы при 503) —
  не менять без необходимости. ЕМИСС: запросы строго последовательно (очередь по хостам в runner).
- Модель пользователя меняем только «Подключить модель» (и опциональное ночное обновление), только с
  резервной копией, без макросов. Паролей не храним и не вводим.

## Важные механизмы (версия 0.3)

- **Разрезы отдельными полями**: `SeriesInfo.dims = [("Показатель", …), ("Регион", …)]` → `series.dims`
  (JSON). Справочник «— ряды.csv» получает в конце столбцы «Показатель», «Разрез 1…4»
  (`packet.cut_values`); «Открыть в Excel» — столбцы с настоящими названиями (`exports.dims_table`).
  Название ряда (`name`) по-прежнему склейка — для подписи. ЕМИСС: измерение «Единица измерения»
  уходит в единицы, «^» вычищается (`fedstat.clean`).
- **ЕМИСС частями**: `FedstatSource._download_in_parts` — части по годам, размер от оценки
  «значений на год» (`CHUNK_CELLS`), при сбое части — пополам до 1 года, после удачи — вдвое больше.
  Дозагрузка: runner передаёт `ctx.last_period` и `ctx.full_reload` (полная раз в 30 дней, отметка
  `meta full:<id>`); при дозагрузке `FetchResult.partial = True` — проверки «исчезли ряды» и «резко
  меньше строк» не применяются. `Source.timeout()` — свой тайм-аут источника.
- **Подключение модели (COM)**: у пользователя (Excel 16, сборка 19127, pywin32, Python 3.13) все три
  первых способа `ListObjects.Add` дали E_INVALIDARG (-2147024809), а `Queries.Add` работает. Поэтому
  `_load_tables` перебирает окружения `VARIANTS` (Excel в фоне / видимый свёрнутый × русские / латинские
  имена запросов `mcode.ASCII_NAMES`) и способы `TABLE_WAYS`; сработавшее запоминается в
  `settings.excel_way`. Таблицы на листе всегда называются Хаб и Хаб_Ряды.
  `com_connect.TABLE_WAYS` — несколько способов `ListObjects.Add`;
  ошибка называет шаг (`StepError`); если запросы добавились, а таблицы нет — модель сохраняется
  «почти подключённой» (`partial`). `com_connect.diagnose` — кнопка «Проверить связь с Excel».
  Тесты на поддельном Excel — `tests/test_com.py`.
- **«Выбрать на странице»**: щелчок по блоку с >3 числами = выбор таблицы (`_analyze.picked_table`,
  сопоставление по строкам или по тексту блока). Если нужное не нашлось, страница прикладывается
  к ошибке (`exc.raw_text` → raw) и попадает в «Отправить Claude».
- Навигаторы ЕМИСС и ЦБ используют один виджет выбора значений `gui/dimlist.py`.
- **Выжимка для модели (0.4)**: в models.yaml у модели `selections: [{id, job, name, filters {поле: [значения]},
  from, to}]`. Поля — разрезы ряда + «Периодичность» (`packet.series_fields`); в filters только поля, где
  отмечено не всё. `packet.model_plan` → (коды, окна дат); `build` отдаёт в посылку только период окна.
  Окно «Данные для модели» — `gui/dialog_select.py`. Подписка «на весь показатель» (`jobs`) осталась,
  но для показателей больше `dialog_add.BIG_JOB` рядов диалог добавления предлагает выборку.

- **Расписание и график выхода (0.5)**: строка `schedule` (см. `schedule.py`, время после «@»);
  `job.release_dates` — даты из вставленного календаря публикаций (`parse_release_text`),
  `job_state.release_next/release_note` — срок, который сообщил источник (`FetchResult.next_release`;
  ЕМИСС — `fedstat.release_from_page` по уже скачанной странице показателя, формат живой страницы ещё
  не проверен). В момент выхода — проверка, затем каждые 2 ч до 23:00, пока нет `last_change`.
  `expected_next` берёт ближайшую дату графика. Задача планировщика — каждые 15 мин (`winsched.INTERVAL`,
  старая задача пересоздаётся при запуске окна — `winsched.upgrade`); пустой проход по расписанию
  выходит сразу, посылки пересобираются не чаще раза в час (`meta packets_built`).

- **Не открывается окно**: пользователь запускает `Запуск с проверкой.bat` (консольный python,
  `-X faulthandler`, пауза в конце, предупреждение о других pythonw.exe) и присылает текст или
  «Ошибка запуска.txt». `crash.StartupWatch`: если окно не ответило за 40 с — стеки всех потоков и шаг
  запуска в тот же файл. Занятая база при миграции (`ALTER TABLE`) → понятная `HubError` вместо молчания.

- **Длинные тексты вешают Tk** (0.5.3): замечание проверки на каждый ряд у показателя с тысячами рядов
  давало сообщение в сотни КБ, и окно зависало на «Обзоре». Теперь `checks.summary` — одно замечание
  на вид с 3 примерами, единицы сравниваются через `checks.unit_key` (без «^»), в окне тексты
  режутся `overview.short`, строк проблем ≤ 40, карантин — одна строка на показатель.

- **0.5.4**: поле, которого нет у части рядов, в выборке — `packet.field_value` (у старых рядов ЕМИСС
  «Вид значения» = «значение за период»; ЕМИСС теперь пишет это поле всем рядам, если видов несколько).
  «Убрать» — `cfg.unsubscribe_codes` одной записью; ряды из «Отдельных рядов» не заносятся в `exclude`
  (раньше это прятало ряды выборок; разовая починка — `fix_054` в `packet.model_plan`). ЕМИСС «CSRF
  блокировка» → свежая страница показателя и повтор (`fedstat.fetch` → `fresh_token`).

- **0.5.5**: расписание — список правил (`parse_rules`, окно `gui/schedule_box.py`: RuleDialog,
  ReleaseDialog). `expected_next` смотрит только на «живые» ряды (последний период не старше одного
  периода от самого свежего) и одним запросом (`store.last_period_ends`). `status.explain` — что значит
  статус (панель под «Мои показатели», «История»). ЕМИСС: если год не грузится или > 2×CHUNK_CELLS —
  `_split_year` делит по самому большому измерению; несчитанный срок → `FetchResult.timing_text` →
  `cache/сроки/<job>.txt` → «Отправить Claude». В тестах компьютер «в Москве» (`conftest.moscow_computer`).
  «＋ В обновления» больше не подписывает модели — после загрузки кнопки «Отдать в модель».

- **0.5.6 — ЕМИСС бережно**: токен ЕМИСС одноразовый (каждый POST его расходует) — `fedstat.fetch` отдаёт
  уже прочитанную страницу только первой выгрузке (`one_shot`), дальше `download()` читает страницу сам, как
  исходный клиент (в 0.3–0.5.5 токен переиспользовался → «CSRF блокировка» на каждой части → лишние
  запросы → 403 на всё). Заголовки браузера `BROWSER_HEADERS` (на «голые» запросы ЕМИСС может отвечать 403),
  куки после проверки во встроенном браузере — `cache/cookies/www.fedstat.ru.json` (`load_cookies`, пишет
  `tab_overview.open_site_check`). `CHUNK_CELLS` 200 тыс. (ЕМИСС советуют ≤ 500 тыс. строк на запрос),
  больше `MAX_REQUESTS` (150) выгрузок — `HubError(TOO_BIG)` без единого запроса. Runner: `blocking(exc)`
  (403/429/BOT) → `hostblock.block`, остальные показатели сайта в этом проходе не трогаются, `due_jobs`
  пропускает сайт на паузе, статус `blocked`; удача — `hostblock.clear`. Карантин: окно
  `tab_overview.review_quarantine` (объяснения `checks.explain`, выключение проверки `checks.switch_off`,
  решение в фоне, `store.accept_quarantine` пакетом).

- **0.5.7 — окна**: кнопки-значки с подсказками (`widgets.icon_button`, `Tooltip`; только символы из BMP —
  Tk 8.6 на Windows не рисует эмодзи вне BMP), панели кнопок с переносом (`FlowBar`), текст по ширине окна
  (`autowrap` — только для растянутых меток), столбцы таблиц делят ширину пропорционально (`fit_columns`).
  «Мои показатели»: ◷ `tab_jobs.JobWindow` (расписание + статус + история; старые имена HistoryWindow/EditWindow
  — псевдонимы), ✎ «Изменить набор данных» — `gui/nav_edit.EditMode` в навигаторах ЕМИСС/ЦБ (тот же job,
  меняются только params). Меню «Ещё ▾» убраны.

- **0.5.8**: html-таблицы с colspan/rowspan — `_tables._grid` (шапка в несколько этажей → «Цена, руб. — Рыночная»),
  таблица «дата | значения» → история (`rows_are_dates`), единицы из шапки столбца (`unit_from_header`).
  ЕМИСС: значения выбора ищутся и по названию (`_key`, `params.select_titles`) — при смене классификатора
  номера меняются; `_coverage` предупреждает, если данные кончаются раньше лет фильтра. Навигатор ЕМИСС:
  поля показателя — с ходом загрузки, кэш `cache/fedstat_info/<id>.json` на сутки, при сбое — начало
  страницы в «Отправить Claude» (`_indicator_failed`). Дешёвая проверка даты обновления (ЦБ) — при любом
  расписании. `ScrollFrame` возвращается наверх при новом содержимом.

- **0.5.9**: длинные таблицы-архивы (> 20 тыс. знаков) больше не считаются раскладкой страницы (раскладка —
  только с вложенными таблицами); строки в `<thead>` или целиком из `<th>`, а также строка под ячейкой шапки
  с rowspan — шапка, даже если в ней числа («Срок, лет — 0.25…20», `_is_head_row`); «12.63» — число, а не
  «день.месяц» (`_tables._is_date` проверяет день ≤ 31, месяц ≤ 12); `unit_from_header` не берёт единицы
  верхнего этажа, если нижний — число; «доходность/КБД» в заголовке → «%». `picked_table` понимает щелчок по
  `<tbody>`. Окно браузера для человека (вход, выбор) — `no_viewport`, страница следует размеру окна.
  Образец — синтетический `samples/web/moex_gcurve_archive.html` (живая страница из облака недоступна).

- **0.6.0 — «Обзор»**: «Новые данные за неделю» — `overview.recent_updates` (по показателю: сумма записей, самый

## Категории ошибок

`errors.py`: network, rate_limit, structure, login, bot, file_busy, check_failed, no_new_data, too_big, internal.
Адаптер поднимает `StructureError` при непонятном ответе, `LoginRequired` — когда нужен вход.
Остальное классифицирует `errors.classify`. Временные (network, rate_limit, file_busy) повторяются с
паузой 15 мин → 30 → … → 6 ч; после `fail_threshold` (3) сбоев подряд статус красный.

## Как запускать тесты

```
pip install -r requirements-dev.txt
python -m pytest -q                       # ядро, источники, посылки, M-шаблоны
xvfb-run -a python -m pytest -q           # плюс проверка окна (в Linux без дисплея)
HUB_CHROMIUM=/opt/pw-browsers/chromium-1194/chrome-linux/chrome xvfb-run -a python -m pytest -q
                                          # плюс «Выбрать на странице» в настоящем Chromium
```

Веб-источники тестируются на сохранённых страницах `samples/web/` (Metro, Металл Торг, Fearnleys):
`tests/test_web.py` подменяет `_web.http_get`. Показатели-образцы — `hub/core/examples.py`.

В облаке Python 3.13 системы может быть без tkinter — используй `python3.12 -m venv`.
Сайты ЦБ/ЕМИСС из облака недоступны: тестируй только на `samples/` (см. `tests/fakes.py`).
Живые ответы пользователь может сохранить командой `python -m hub samples` (→ `samples/live/`).

## Как добавить источник

См. `КАК_ДОБАВИТЬ_ИСТОЧНИК.md`. Коротко: модуль в `hub/sources/` с классом-наследником `Source`
(`kind`, `title`, `fetch`, при возможности `check_updated`), тест на образце в `samples/`.

## Что проверить у пользователя

Всё, что требует Windows, Excel или живых сайтов, — в `ПРОВЕРКА_НА_WINDOWS.md`. Дополняй его, если
добавляешь такое.
